# Machine-learned interatomic potentials: hands-on tutorials

Three tutorials to train neural network potentials with [n2p2](https://compphysvienna.github.io/n2p2/) and run molecular dynamics with them in [CP2K](https://www.cp2k.org/). They run on **Google Colab**: you only need a web browser and a Google account.

Click on a tutorial's button to open it in Colab, then follow the [student guide (PDF)](colab_guide.pdf). Do the tutorials in order.

| Tutorial | Open | Lesson notes | Computing time |
|---|---|---|---|
| 1. Zundel ion, H<sub>5</sub>O<sub>2</sub><sup>+</sup> | [![Open in Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/zacway/TP-MLIP/blob/main/tutorial_01_zundel/zundel.ipynb) | [PDF](tutorial_01_zundel/lesson_zundel.pdf) | ~10 min |
| 2. Protonated water cluster, (H<sub>2</sub>O)<sub>6</sub>H<sup>+</sup> | [![Open in Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/zacway/TP-MLIP/blob/main/tutorial_02_wclusters/wclusters.ipynb) | [PDF](tutorial_02_wclusters/lesson_wclusters.pdf) | ~17 min |
| 3. Published models for aqueous systems | [![Open in Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/zacway/TP-MLIP/blob/main/tutorial_03_wsystems/wsystems.ipynb) | | ~18 min |

In short: open the notebook, run its first cell (setup, 1 to 2 minutes), then run the cells one by one from top to bottom.
